# jsx-a11y rules

Generated by `pnpm docs:rules`. Deprecated rules are omitted.

| Rule | Setting | Purpose |
| --- | --- | --- |
| `jsx-a11y-x/alt-text` | error | Enforce all elements that require alternative text have meaningful information to relay back to end user. |
| `jsx-a11y-x/anchor-ambiguous-text` | error | Enforce `<a>` text to not exactly match "click here", "here", "link", or "a link". |
| `jsx-a11y-x/anchor-has-content` | error | Enforce all anchors to contain accessible content. |
| `jsx-a11y-x/anchor-is-valid` | error | Enforce all anchors are valid, navigable elements. |
| `jsx-a11y-x/aria-activedescendant-has-tabindex` | error | Enforce elements with aria-activedescendant are tabbable. |
| `jsx-a11y-x/aria-props` | error | Enforce all `aria-*` props are valid. |
| `jsx-a11y-x/aria-proptypes` | off | Enforce ARIA state and property values are valid. |
| `jsx-a11y-x/aria-role` | error | Enforce that elements with ARIA roles must use a valid, non-abstract ARIA role. |
| `jsx-a11y-x/aria-unsupported-elements` | error | Enforce that elements that do not support ARIA roles, states, and properties do not have those attributes. |
| `jsx-a11y-x/autocomplete-valid` | error | Enforce that autocomplete attributes are used correctly. |
| `jsx-a11y-x/click-events-have-key-events` | error | Enforce a clickable non-interactive element has at least one keyboard event listener. |
| `jsx-a11y-x/control-has-associated-label` | off | Enforce that a control (an interactive element) has a text label. |
| `jsx-a11y-x/heading-has-content` | error | Enforce heading (`h1`, `h2`, etc) elements contain accessible content. |
| `jsx-a11y-x/html-has-lang` | error | Enforce `<html>` element has `lang` prop. |
| `jsx-a11y-x/iframe-has-title` | error | Enforce iframe elements have a title attribute. |
| `jsx-a11y-x/img-redundant-alt` | error | Enforce `<img>` alt prop does not contain the word "image", "picture", or "photo". |
| `jsx-a11y-x/interactive-supports-focus` | error | Enforce that elements with interactive handlers like `onClick` must be focusable. |
| `jsx-a11y-x/label-has-associated-control` | error | Enforce that a `label` tag has a text label and an associated control. |
| `jsx-a11y-x/lang` | error | Enforce lang attribute has a valid value. |
| `jsx-a11y-x/media-has-caption` | error | Enforces that `<audio>` and `<video>` elements must have a `<track>` for captions. |
| `jsx-a11y-x/mouse-events-have-key-events` | error | Enforce that `onMouseOver`/`onMouseOut` are accompanied by `onFocus`/`onBlur` for keyboard-only users. |
| `jsx-a11y-x/no-access-key` | error | Enforce that the `accessKey` prop is not used on any element to avoid complications with keyboard commands used by a screen reader. |
| `jsx-a11y-x/no-aria-hidden-on-focusable` | error | Disallow `aria-hidden="true"` from being set on focusable elements. |
| `jsx-a11y-x/no-autofocus` | error | Enforce autoFocus prop is not enabled. |
| `jsx-a11y-x/no-distracting-elements` | error | Enforce distracting elements are not used. |
| `jsx-a11y-x/no-interactive-element-to-noninteractive-role` | error | Disallow interactive elements being assigned non-interactive roles. |
| `jsx-a11y-x/no-noninteractive-element-interactions` | error | Disallow non-interactive elements being assigned mouse or keyboard event listeners. |
| `jsx-a11y-x/no-noninteractive-element-to-interactive-role` | error | Disallow non-interactive elements being assigned interactive roles. |
| `jsx-a11y-x/no-noninteractive-tabindex` | error | Enforce `tabIndex` only be declared on interactive elements. |
| `jsx-a11y-x/no-redundant-roles` | error | Enforce explicit role property is not the same as implicit/default role property on element. |
| `jsx-a11y-x/no-static-element-interactions` | error | Enforce that non-interactive, visible elements (such as `<div>`) that have click handlers use the role attribute. |
| `jsx-a11y-x/prefer-tag-over-role` | error | Enforces using semantic DOM elements over the ARIA `role` property. |
| `jsx-a11y-x/role-has-required-aria-props` | error | Enforce that elements with ARIA roles must have all required attributes for that role. |
| `jsx-a11y-x/role-supports-aria-props` | error | Enforce that elements with explicit or implicit roles defined contain only `aria-*` properties supported by that `role`. |
| `jsx-a11y-x/scope` | error | Enforce `scope` prop is only used on `<th>` elements. |
| `jsx-a11y-x/tabindex-no-positive` | error | Enforce `tabIndex` value is not greater than zero. |
