# react-hooks rules

Generated by `pnpm docs:rules`. Deprecated rules are omitted.

| Rule | Setting | Purpose |
| --- | --- | --- |
| `react-hooks/exhaustive-deps` | off | verifies the list of dependencies for Hooks like useEffect and similar |
| `react-hooks/rules-of-hooks` | off | enforces the Rules of Hooks |
| `react-hooks/hooks` | off | Validates the rules of hooks |
| `react-hooks/capitalized-calls` | error | Validates against calling capitalized functions/methods instead of using JSX |
| `react-hooks/static-components` | off | Validates that components are static, not recreated every render. Components that are recreated dynamically can reset state and trigger excessive re-rendering |
| `react-hooks/use-memo` | off | Validates usage of the useMemo() hook against common mistakes. See [`useMemo()` docs](https://react.dev/reference/react/useMemo) for more information. |
| `react-hooks/void-use-memo` | off | Validates that useMemos always return a value and that the result of the useMemo is used by the component/hook. See [`useMemo()` docs](https://react.dev/reference/react/useMemo) for more information. |
| `react-hooks/preserve-manual-memoization` | error | Validates that existing manual memoized is preserved by the compiler. React Compiler will only compile components and hooks if its inference [matches or exceeds the existing manual memoization](https://react.dev/learn/react-compiler/introduction#what-should-i-do-about-usememo-usecallback-and-reactmemo) |
| `react-hooks/memo-dependencies` | off | Validates that useMemo() and useCallback() specify comprehensive dependencies without extraneous values. See [`useMemo()` docs](https://react.dev/reference/react/useMemo) for more information. |
| `react-hooks/incompatible-library` | error | Validates against usage of libraries which are incompatible with memoization (manual or automatic) |
| `react-hooks/immutability` | off | Validates against mutating props, state, and other values that [are immutable](https://react.dev/reference/rules/components-and-hooks-must-be-pure#props-and-state-are-immutable) |
| `react-hooks/globals` | off | Validates against assignment/mutation of globals during render, part of ensuring that [side effects must render outside of render](https://react.dev/reference/rules/components-and-hooks-must-be-pure#side-effects-must-run-outside-of-render) |
| `react-hooks/refs` | off | Validates correct usage of refs, not reading/writing during render. See the "pitfalls" section in [`useRef()` usage](https://react.dev/reference/react/useRef#usage) |
| `react-hooks/memoized-effect-dependencies` | off | Validates that effect dependencies are memoized |
| `react-hooks/exhaustive-effect-dependencies` | off | Validates that effect dependencies are exhaustive and without extraneous values |
| `react-hooks/set-state-in-effect` | off | Validates against calling setState synchronously in an effect. This can indicate non-local derived data, a derived event pattern, or improper external data synchronization. |
| `react-hooks/no-deriving-state-in-effects` | off | Validates against deriving values from state in an effect |
| `react-hooks/error-boundaries` | off | Validates usage of error boundaries instead of try/catch for errors in child components |
| `react-hooks/purity` | off | Validates that [components/hooks are pure](https://react.dev/reference/rules/components-and-hooks-must-be-pure) by checking that they do not call known-impure functions |
| `react-hooks/set-state-in-render` | off | Validates against setting state during render, which can trigger additional renders and potential infinite render loops |
| `react-hooks/invariant` | off | Internal invariants |
| `react-hooks/todo` | off | Unimplemented features |
| `react-hooks/syntax` | off | Validates against invalid syntax |
| `react-hooks/unsupported-syntax` | off | Validates against syntax that we do not plan to support in React Compiler |
| `react-hooks/config` | error | Validates the compiler configuration options |
| `react-hooks/gating` | error | Validates configuration of [gating mode](https://react.dev/reference/react-compiler/gating) |
| `react-hooks/rule-suppression` | off | Validates against suppression of other rules |
| `react-hooks/fbt` | off | Validates usage of fbt |
