# storybook rules

Generated by `pnpm docs:rules`. Deprecated rules are omitted.

| Rule | Setting | Purpose |
| --- | --- | --- |
| `storybook/await-interactions` | error | Interactions should be awaited |
| `storybook/context-in-play-function` | off | Pass a context when invoking play function of another story |
| `storybook/csf-component` | error | The component property should be set |
| `storybook/default-exports` | error | Story files should have a default export |
| `storybook/hierarchy-separator` | error | Deprecated hierarchy separator in title property |
| `storybook/meta-inline-properties` | error | Meta should only have inline properties |
| `storybook/meta-satisfies-type` | error | Meta should use `satisfies Meta` |
| `storybook/no-redundant-story-name` | error | A story should not have a redundant name property |
| `storybook/no-renderer-packages` | error | Do not import renderer packages directly in stories |
| `storybook/no-stories-of` | error | storiesOf is deprecated and should not be used |
| `storybook/no-title-property-in-meta` | error | Do not define a title in meta |
| `storybook/no-uninstalled-addons` | off | This rule identifies storybook addons that are invalid because they are either not installed or contain a typo in their name. |
| `storybook/prefer-pascal-case` | error | Stories should use PascalCase |
| `storybook/story-exports` | error | A story file must contain at least one story export |
| `storybook/use-storybook-expect` | error | Use expect from `@storybook/test`, `storybook/test` or `@storybook/jest` |
| `storybook/use-storybook-testing-library` | off | Do not use testing-library directly on stories |
