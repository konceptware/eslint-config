# import rules

Generated by `pnpm docs:rules`. Deprecated rules are omitted.

| Rule | Setting | Purpose |
| --- | --- | --- |
| `import-x/no-unresolved` | off | Ensure imports point to a file/module that can be resolved. |
| `import-x/named` | off | Ensure named imports correspond to a named export in the remote file. |
| `import-x/default` | off | Ensure a default export is present, given a default import. |
| `import-x/namespace` | off | Ensure imported namespaces contain dereferenced properties as they are dereferenced. |
| `import-x/no-namespace` | off | Forbid namespace (a.k.a. "wildcard" `*`) imports. |
| `import-x/export` | off | Forbid any invalid exports, i.e. re-export of the same name. |
| `import-x/no-mutable-exports` | error | Forbid the use of mutable exports with `var` or `let`. |
| `import-x/extensions` | off | Ensure consistent use of file extension within the import path. |
| `import-x/no-restricted-paths` | off | Enforce which files can be imported in a given folder. |
| `import-x/no-internal-modules` | off | Forbid importing the submodules of other modules. |
| `import-x/group-exports` | off | Prefer named exports to be grouped together in a single export declaration. |
| `import-x/no-relative-packages` | error | Forbid importing packages through relative paths. |
| `import-x/no-relative-parent-imports` | off | Forbid importing modules from parent directories. |
| `import-x/consistent-type-specifier-style` | error | Enforce or ban the use of inline type-only markers for named imports. |
| `import-x/no-self-import` | error | Forbid a module from importing itself. |
| `import-x/no-cycle` | error | Forbid a module from importing a module with a dependency path back to itself. |
| `import-x/no-named-default` | error | Forbid named default exports. |
| `import-x/no-named-as-default` | error | Forbid use of exported name as identifier of default export. |
| `import-x/no-named-as-default-member` | off | Forbid use of exported name as property of default export. |
| `import-x/no-anonymous-default-export` | error | Forbid anonymous values as default exports. |
| `import-x/no-rename-default` | off | Forbid importing a default export by a different name. |
| `import-x/no-unused-modules` | off | Forbid modules without exports, or exports without matching import in another module. |
| `import-x/no-commonjs` | error | Forbid CommonJS `require` calls and `module.exports` or `exports.*`. |
| `import-x/no-amd` | error | Forbid AMD `require` and `define` calls. |
| `import-x/no-duplicates` | error | Forbid repeated import of the same module in multiple places. |
| `import-x/first` | error | Ensure all imports appear before other statements. |
| `import-x/max-dependencies` | off | Enforce the maximum number of dependencies a module can have. |
| `import-x/no-extraneous-dependencies` | error | Forbid the use of extraneous packages. |
| `import-x/no-absolute-path` | error | Forbid import of modules using absolute paths. |
| `import-x/no-nodejs-modules` | off | Forbid Node.js builtin modules. |
| `import-x/no-webpack-loader-syntax` | error | Forbid webpack loader syntax in imports. |
| `import-x/order` | error | Enforce a convention in module import order. |
| `import-x/newline-after-import` | error | Enforce a newline after import statements. |
| `import-x/prefer-default-export` | off | Prefer a default export if module exports a single name or multiple names. |
| `import-x/prefer-namespace-import` | off | Enforce using namespace imports for specific modules, like `react`/`react-dom`, etc. |
| `import-x/no-default-export` | off | Forbid default exports. |
| `import-x/no-named-export` | off | Forbid named exports. |
| `import-x/no-dynamic-require` | error | Forbid `require()` calls with expressions. |
| `import-x/unambiguous` | error | Forbid potentially ambiguous parse goal (`script` vs. `module`). |
| `import-x/no-unassigned-import` | off | Forbid unassigned imports. |
| `import-x/no-useless-path-segments` | error | Forbid unnecessary path segments in import and require statements. |
| `import-x/dynamic-import-chunkname` | off | Enforce a leading comment with the webpackChunkName for dynamic imports. |
| `import-x/no-import-module-exports` | error | Forbid import statements with CommonJS module.exports. |
| `import-x/no-empty-named-blocks` | error | Forbid empty named import blocks. |
| `import-x/exports-last` | off | Ensure all exports appear after other statements. |
| `import-x/no-deprecated` | off | Forbid imported names marked with `@deprecated` documentation tag. |
